# Overview

For 2 weeks of my time I decided it was a good idea to learn about and how to program using java. I knew java existed, but had never touched it. I decided that programming a simple grocery list tracker was the best way to get started on learning and applying that learning.

The program can read and write to a file, takes user input, and also can read from and wright to a file.
